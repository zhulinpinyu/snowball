# Snowball — 家庭资产账本

记录家庭各平台（支付宝/微信/雪球…）基金、股票投资的手工快照工具：每隔一段时间抄录各持仓的市值与累计收益，看家庭总资产趋势、按人/平台/类型的占比、单个标的的走势。

## 概念

- **快照**：某一天的全体持仓记录
- **持仓记录**：谁、在哪个平台、持有什么标的、市值多少、累计收益多少（均从 App 抄录）
- 详见 [CONTEXT.md](./CONTEXT.md)，决策见 [docs/adr/](./docs/adr/)

## 开发

```bash
npm install
npm run dev        # 本地开发
npm test           # vitest（快照库领域核心）
npm run build      # 纯静态产物，部署到任意静态服务器后在微信中打开
```

## 数据

数据存于浏览器 localStorage（单键），可在「设置」页导出/导入 JSON 备份迁移。
