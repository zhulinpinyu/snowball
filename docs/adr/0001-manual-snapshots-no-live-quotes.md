# ADR 0001 — 快照式手工记录，不自动拉取行情

日期：2025-08-29
状态：已被 ADR 0002 取代（记录模型改为 持仓 × 实时现价 + 记录点；本文保留作历史）

## 背景

Snowball 的定位是家庭投资的"定期体检"工具：每隔一段时间手工记录各持仓的市值与累计收益。技术上完全可以通过基金代码接入行情 API 自动拉净值。

## 决策

不自动拉取行情。基金/股票代码仅作为标的的唯一标识（同一标的跨平台归并），每期数字由用户从所属 App 手工抄录。

## 理由

- 各 App 显示的"累计收益"口径不一且含平台内行为（如定投、分红方式），自动行情无法还原 App 实际数字。
- 抄录两个数字（市值 + 累计收益）成本极低，与"隔段时间记一下"的使用节奏匹配。
- 免除行情数据源依赖与网络失败处理，纯静态部署即可运行。

## 后果

- 无法做到实时/高频记录，趋势粒度 = 快照频率。
- 若未来要自动化，基金代码字段已保留，可作为接入行情 API 的钩子，属可逆扩展。
