# ADR 0004 — 每日估值快照：曲线由「人工记录点 + 自动价格历史」共同驱动

日期：2026-09-03
状态：已接受（补充 ADR 0002，不取代它）

## 背景

ADR 0002 定的是「只有份额/成本/余额变化时才记录，现价自动变动不构成记录」。实际用下来暴露一个问题：
只要用户在某个日期（例如季度末）记过一次、之后份额和余额都没变，`valuationSeries` 就只有这一个采样点，
总览的走势图变成「一个点 + 实时值」，看不到历史每天的涨跌。

用户的原始预期是：**打开/刷新页面、行情有更新，就应该在曲线上留下一个点**，这样才能看到每天的总资产变化。
现价虽然实时刷新，但刷新只改内存里的 `QuoteView`，从不写库，行情涨跌完全不留痕。

## 决策

把「事实」和「估值」拆成两条序列：

- **人工记录点（`positionPoints` / `cashPoints`，语义不变）**：只记份额/成本/余额的人工改动，可补记、可删除纠错。
- **估值快照（`valuationPoints`，新增）**：`{ positionId, date, price }`，按 `(持仓, 行情日期)` upsert。
  刷新行情成功后，对每个拿到「真实行情」的持仓自动落点；`stale`（回退价）或无行情日期的持仓当天跳过，绝不把回退价写进历史。
- **日期取行情自带日期**（基金=净值日期、股票=交易日），不是打开 App 的日期。周末/停牌行情日期不前进 → 不产生假点；
  同一行情日重复刷新只更新，不新增（每天最多一个点）。
- **曲线采样日 = 人工记录点日期 ∪ 估值快照日期**。某日估值时：份额/成本/余额仍取该日 as-of 的最近人工记录点；
  价格优先用「当天的人工记录价」（当天记过），否则用 ≤该日的最近快照价，都没有再退回人工记录点里的记录价。
- **现金不落快照**：现金没有行情日，按 ≤该日的最近余额计入（即原有 as-of 逻辑）。
- 自动记录默认开启，可在设置页关闭；关闭后曲线退回「只由人工记录点驱动」。

## 后果

- 只要打开过 App（或有手动刷新），每天就有一个采样点，总览能看到每日涨跌；涨跌只体现在曲线上（悬停看当日总值），不做额外的明细列表。
- 没有打开过的日子不采样，曲线上是直连的缺口（不引入历史净值接口去回补，接口不在 ADR 0003 范围内）。需要时可用「补记」手动落点。
- 曲线的日间变化口径是总资产环比，**包含现金转入转出**，不是纯投资盈亏。
- 不污染人工历史：持仓的「记录」对话框仍只列人工记录点，不显示自动快照。
- 每日采样带来持续增量，但量级很小（持仓数 × 天数，5 个持仓 3 年约 5500 条），永久保留、不自动清理。
- 存储格式向后兼容是硬约束：`valuationPoints` / `autoValuation` 是**可选校验字段**，老库/老备份缺它们仍判有效，
  由 `normalizeDatabase` 补默认值（空数组 / 开启）。绝不能因缺新字段把老数据判无效——那会走 `emptyDatabase()` 清库分支。
