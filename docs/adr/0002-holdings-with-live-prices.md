# ADR 0002 — 持仓模型 + 实时现价，取代快照抄录

日期：2026-09-02
状态：已接受（取代 ADR 0001）

## 背景

v1 之前的 MVP 按"快照"设计：整期抄录每笔持仓的市值与累计收益，代码仅作标识、不拉行情（ADR 0001）。
实际体验的问题：每期要抄市值和累计收益两个数；累计收益是各 App 的口径（含定投、分红、部分赎回），
与"家庭现在值多少"脱节；整期快照要求全家人把资产在同一天对齐，抄录成本高、容易漏。

## 决策

改为"持仓 + 记录点"模型，现价实时化：

- 持仓/现金账户是**常驻实体**：基金/股票记 份额(股数) 与 持仓成本价，现金账户记余额，均手输、可随时改。
- 现价由行情接口自动取得（基金 = 最新单位净值，股票 = 最新行情价），市值 = 份额 × 现价，打开应用即最新。
- 盈亏口径 = 持仓浮动盈亏 (现价 − 成本价) × 份额；不追踪已实现收益，不采用 App"累计收益"口径。
- 只有份额/成本/余额变化时才"记录"，打一个带日期的记录点（默认今天、可补记过去、可编辑删除纠错）；
  历史估值曲线由记录点驱动，不再要求整期对齐。

## 后果

- 现价依赖第三方行情接口：网络或接口变更时需降级（沿用上次价并标记"行情未更新"），不能阻断查看。
- 持仓成本价需用户随买卖自行摊薄维护，否则浮动盈亏失真——这是接受的手工成本，不做自动摊薄助手（见 spec 0002 范围）。
- 明确放弃"累计收益/已实现收益"口径，是范围收缩而非功能缺失。
- 同代码可跨人/跨平台各自持仓；总览与占比按持仓/账户汇总。

行情数据源选型见 ADR 0003。
